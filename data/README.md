# Data Availability

The original crime and storm-event datasets used in this analysis were provided through university coursework and are not redistributed in this repository because no explicit redistribution license was provided.

This repository focuses on the analytical workflow, code, visualizations, summarized results, and interpretation developed for portfolio demonstration.

The crime analysis used Miami Police Department crime records, while the storm analysis used Florida storm-event records. The datasets were cleaned, filtered, and aggregated to the monthly level for comparison.
